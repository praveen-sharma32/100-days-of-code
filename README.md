# 100 Days of Code — Basic Coding with C

Coursework & Daily Coding Challenge by UPES (University of Petroleum and Energy Studies).

## 📊 Challenge Overview

- **Curriculum**: [100 Days of Code — Basic Coding with C](https://maitysoumik.github.io/basic-coding-with-c/)
- **Phase 1 (Days 1–50)**: 2 questions per day (Q1 to Q100)
- **Phase 2 (Days 51–100)**: 1 question per day (Q101 to Q150)
- **Total Problems**: 150 problems solved
- **Timeline**: August 10, 2026 – November 21, 2026

## 📁 Repository Structure

Each day's solutions are organized in dedicated folders (Day01, Day02, ... Day100) containing individual question solution files (q1.c, q2.c, etc.).
